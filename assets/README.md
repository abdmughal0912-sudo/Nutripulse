# NutriPulse original visual assets

These four raster assets were generated with the built-in OpenAI image-generation workflow for
NutriPulse and are bundled locally so the Streamlit interface remains visually complete offline.

- `nutripulse_hero.jpg`: wide dark clinical-nutrition hero with a healthy meal and data motifs.
- `lab_nutrition.jpg`: laboratory-report and healthy-food section artwork.
- `web_insights.jpg`: trusted web-research and API connectivity section artwork.
- `food_vision_luxury.jpg`: obsidian, emerald and champagne-gold NutriLens food-analysis hero.
- `nutripulse_mark.svg`: code-native application and API favicon mark.

All prompts requested original imagery with no people, logos, brand names, readable text or
watermarks. The images are decorative interface assets and do not depict a diagnosis or treatment.
They are optimized to 1,280-pixel JPEG files to keep the downloadable application package compact.
